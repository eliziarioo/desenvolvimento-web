Semântica HTML

Aqui você irá aprender sobre a linguagem HTML e suas principais tags!

O HTML(Linguagem de Marcação de Hipertexto) é o esqueleto das páginas da web. Ele usa marcas chamadas tags para organizar textos,
imagens, links e botões, permitindo que o navegador entenda e exiba o site.

O que o HTML faz:

  • Cria a base de um site
  • Mostra aonde ficam títulos e parágrafos
  • Insere imagens e vídeos
  • Cria links para outras páginas

Estrutura Básica:

  • Usar tags de abertura e fechamento como h1 e ol
  • O bloclo html guarda todo o código
  • A parte head cuida dos dados das páginas
  • O corpo body mostra o conteúdo visível

Estilizando páginas com CSS!

O CSS (Cascading Style Sheets, ou Folhas de Estilo em Cascata) é a linguagem de estilo usada para definir a aparência visual de páginas web criadas com HTML. Enquanto o HTML cuida da estrutura, o CSS define cores, fontes, tamanhos, espaçamentos e o layout final do site.
