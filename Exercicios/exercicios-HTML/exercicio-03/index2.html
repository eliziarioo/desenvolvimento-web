Estilizando páginas com CSS

Introdução ao CSS e como usa-lo para estilizar páginas

Como foi dito na página anterior, o CSS é a linguagem de estilo usada para definir a aparência visual de páginas web criadas com HTML.

Conceitos Básicos:

  • Seletores: Indicam qual elemento HTML receberá o estilo
  • Propriedades: O aspecto visual que você quer mudar, como color (cor do texto) ou font-size (tamanho da fonte).
  • Valores: O valor que você quer aplicar à propriedade, como red (vermelho) ou 16px (tamanho da fonte).

Formas de aplicar o CSS:

  • Externo: Um arquivo .css separado que é ligado ao documento HTML (o método mais recomendado)
  • Interno: Estilos colocados dentro da tag style no próprio arquivo HTML.
  • Inline: Estilos aplicados diretamente na linha de um elemento HTML específico.
