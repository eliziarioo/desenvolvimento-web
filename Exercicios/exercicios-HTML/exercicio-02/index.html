Aprendendo a semântica HTML

Lista de elemntos semânticos: São elementos HTML que descrevem o significado e a função do conteúdo dentro da página.
Eles ajudam o navegador, mecanismos de busca e tecnologias assistivas a entenderem a estrutura do site.

  • header
  • main
  • aside
  • section
  • article

Lista de elementos não semânticos: São elementos que não indicam o significado do conteúdo,
servindo principalmente para organizar, agrupar ou estilizar elementos.

  • div
  • span
